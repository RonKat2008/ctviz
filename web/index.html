III. Methods

How a sentence becomes a cited figure. The model plans; deterministic code does everything that touches a number.

  1. Planner

    An LLM maps the question onto a typed QueryPlan over the ClinicalTrials.gov API catalog: search terms, filters, analysis kind, chart type.

  2. Overlay & checks

    Your structured fields overwrite the plan by code. Static checks reject impossible plans and record every adjustment.

  3. Probe

    A count-only request sizes each cohort before any bulk fetch, catching empty or runaway queries early.

  4. Judge

    A second model reviews the plan against the question; one revision is allowed, and the verdict is reported, never hidden.

  5. Fetch

    Paged, cached requests pull the full study records. Truncation is declared in data coverage.

  6. Strict match

    Full-text hits are re-checked field by field; trials that only matched loosely are excluded, with a reason.

  7. Aggregate & cite

    Each datum is built with a predicate and one citation per trial: an NCT id, an RFC 6901 pointer and the exact excerpt.

  8. Independent verifier

    A separate pass re-evaluates every predicate and excerpt against the raw records and recounts totals before the response ships.
